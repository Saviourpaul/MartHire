# Onboarding visual asset notes

The user-provided reference, [Made in Webflow Assets](https://webflow.com/made-in-webflow/assets), is a gallery of websites built by the Webflow community. Its recruitment-tagged examples are individual projects such as those listed in [Webflow's recruiting showcase](https://webflow.com/made-in-webflow/recruiting). The gallery does not grant a general license to copy artwork from every listed project.

Webflow's asset guidance says uploaded assets are publicly accessible and that users should only distribute assets they have the right to use ([Webflow Assets panel guidance](https://help.webflow.com/hc/en-us/articles/33961269934227-Assets-panel)). Because the relevant community projects did not provide a verified license for reuse in this repository, no third-party image was downloaded or hot-linked.

The onboarding screens instead use `public/asset/marthire/onboarding/hiring-workspace.svg`, a locally authored vector created for Marthire. It depicts a recruitment dashboard, candidate profiles, and review progress using the platform's navy, lavender, lime, and neutral colors. The SVG is self-contained, scales without raster artifacts, has no external requests or embedded scripts, and is marked decorative in the layout because the same workflow is explained in adjacent text.
